# Softex TrendsIA — P0: Primeiro Fluxo com LLM

Projeto desenvolvido por mim para a trilha de Inteligência Artificial da Softex Campinas (PBL).

## 1. Problema Escolhido
> "Eu transformo anotações livres e desorganizadas em uma lista estruturada de pontos-chave e ações pendentes."

## 2. Objetivo
Construir uma aplicação Python local, segura e reproduzível que recebe uma entrada textual via terminal, comunica-se com a API de um LLM e exibe o resultado formatado.

## 3. Ambiente e Dependências
* Python 3.10+
* Ambiente virtual isolado (`.venv`)
* Dependências listadas em `requirements.txt`

## 4. Evolução do Projeto (Marcos PBL)
- [ ] **Nível Básico** (`p0-basico`): Núcleo funcional da chamada ao LLM.
- [ ] **Nível Intermediário** (`p0-intermediario`): Tratamento de erros e modularização.
- [ ] **Nível Avançado** (`p0-avancado`): Reprodutibilidade, testes e relatório.
